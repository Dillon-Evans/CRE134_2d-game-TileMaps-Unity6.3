CRE132 T06_EnemyAI (Finished)
=============================

Open it in Unity Hub: Add > Add project from disk, choose this folder, and use Unity 6000.3.11f1.
The first time it opens, Unity imports everything; that takes a minute or two.

The scene is in Assets/_game/Scenes/TopDown/. This is the finished sample, to compare with your own.
